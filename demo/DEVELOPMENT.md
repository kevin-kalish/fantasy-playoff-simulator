# Demo V0 acceptance criteria

- Weekly intelligence JSON can be exported without exposing credentials.
- Dashboard opens locally with no package dependencies.
- Overview shows record, seed, playoff probability, championship probability, matchup win probability, and action count.
- Lineup view shows starters and projections.
- Playoffs view shows seed distribution.
- Actions view shows GM recommendations.
- Projection trust/fallback state is visible.
- Missing report data produces an actionable empty state rather than a blank page.
